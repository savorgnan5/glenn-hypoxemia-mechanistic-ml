# Reproducibility materials
Frozen reviewer-revision analysis for the Glenn hypoxemia mechanistic recoverability study. No patient-level clinical data are included.

Primary model: 150,000 generated states (30,000 per encoded mechanism), SVC saturation broad plausibility filter 20%-90%, fixed seed 20260812, multinomial logistic regression, and 500-tree random-forest comparator.

Files include executable analysis code, final balanced and unbalanced synthetic datasets, results.json, sensitivity cohort-flow table, internal calibration bins, and final manuscript figures. The numerical classification results quantify internal recoverability in the simulation and are not estimates of clinical diagnostic accuracy.
